ℹ️ Notice d'utilisation — Rapport de contrôle Parcs & Jardins

Sélection du parc

1
Choisissez la ville en appuyant sur Issy-les-Moulineaux ou Vanves pour filtrer la liste.
2
Sélectionnez le Parc ou Square dans le menu déroulant filtré, ou appuyez sur A‑Z pour ouvrir la liste alphabétique.
3
L'adresse et la ville se remplissent automatiquement. Vous pouvez aussi appuyer sur 📍 pour vous géolocaliser : le parc le plus proche sera suggéré.

Contrôleur

4
Choisissez un Contrôleur dans le menu ou saisissez votre Prénom et NOM librement. Les deux champs se verrouillent mutuellement.

Rubriques de contrôle

5
Pour chaque rubrique, sélectionnez l'état général en appuyant sur une pastille :
Conforme À surveiller Intervention Urgent / mise en sécurité
6
Cochez les points défectueux constatés dans la liste de chaque rubrique.
7
Utilisez + Ajouter bloc pour ajouter des observations et photos. Appuyez sur 🗑️ Supprimer bloc pour retirer le dernier bloc.

Ajouter une photo

1
📷 Prendre une photo : ouvre l'appareil photo de votre téléphone directement.
2
🖼️ Choisir depuis la galerie : sélectionne une ou plusieurs photos existantes.
3
Pour supprimer une photo, appuyez sur ✕ Supprimer sous la miniature.
💡
Les photos sont compressées automatiquement pour ne pas alourdir le fichier.

Sauvegarde automatique

1
Le formulaire se sauvegarde automatiquement lorsque vous quittez l'application ou passez en arrière-plan (notification 💾 Sauvegarde automatique…).
2
À la réouverture, un message vous propose de reprendre le brouillon ou de commencer un nouveau rapport.

Sauvegarde manuelle

3
Appuyez sur 💾 Sauvegarder pour enregistrer le brouillon manuellement à tout moment.
4
📂 Charger : reprendre un brouillon existant. 🗑️ Supprimer : effacer un brouillon.

Export / Import

5
📤 Exporter : télécharge le rapport au format JSON pour l'archiver ou le transmettre.
6
📥 Importer : charge un fichier JSON exporté précédemment pour continuer la saisie.
⚠️
Les brouillons sont stockés localement sur l'appareil (IndexedDB). Ils ne sont pas accessibles depuis un autre appareil sans export/import.

Générer le PDF

1
Appuyez sur 📋 Générer PDF : le rapport complet (rubriques, observations, photos) est téléchargé au format PDF.
💡
Le nom du fichier est généré automatiquement : Controle_NomParc_JJ-MM-AA_Prénom_NOM.pdf

Envoyer par mail

2
Appuyez sur ✉️ Envoyer par mail : une fenêtre affiche le message pré-rédigé avec l'objet, le destinataire et la copie.
3
Appuyez sur Ouvrir dans la messagerie : Outlook (ou votre client mail) s'ouvre avec le message prêt à envoyer. Joignez le PDF manuellement avant d'envoyer.

Formulaire papier (A4 recto-verso)

4
Appuyez sur 🖨️ Formulaire papier pour imprimer un formulaire vierge à remplir au crayon.
5
Dans la boîte d'impression, vérifiez ces paramètres :
  • Format : A4 Paysage
  • Recto-verso : activé (retourner sur le bord long)
  • En-têtes et pieds de page : décoché
  • Marges : Aucune
📱
Sur mobile, l'impression passe par le menu de partage de Chrome → Imprimer.
